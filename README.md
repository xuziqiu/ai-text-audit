# 文本审计 · XZQ Text Audit

为文章、报告和口播稿提供有依据的质量审查。

文本审计从完整正文出发，核查事实与推理，评估结构、表达和实际成效，生成包含六维评分、重点分析和修改建议的报告。它帮助写作者在修改前看清：文章哪些部分成立，哪些问题影响结论，应该先处理什么。

这是 `xzq-text-audit` Skill 的公开发布仓库，包含完整指令、参考文件、评分结构和运行脚本。

[项目介绍](https://xuziqiu.site/projects/text-audit/) · [Skill 入口](SKILL.md)

## 适合什么稿件

- 解释文章、评论、研究或工作报告、口播稿等完整非虚构文本。
- 包含叙述、场景、比喻或情绪表达，但仍承担事实、解释或说服任务的混合文本。
- 发布前审稿、事实与逻辑核查、修改前的整体评估。

诗歌、纯文学与虚构作品的审美评价不在适用范围。孤立短句和缺少上下文的片段通常不启动完整审计。

本 Skill 评价文本质量，不判断文字是否由 AI 生成。审计结束后提供修改建议，由用户决定是否另行改稿。

## 会得到什么

报告先给出总体结论，再展开依据：

1. 结论速览与总体结论；
2. 六维评估与文章行文骨架；
3. 有原文依据的重点审计及其他关键发现；
4. 综合分析与修改建议，包括应当保留的内容；
5. 关键事实核查及来源。

六维评分采用十分制，分别评价：

| 维度 | 关注的问题 |
| --- | --- |
| 任务与成效 | 文章是否完成了它承担的任务 |
| 事实与材料 | 关键事实是否可靠，材料能否支持结论 |
| 推理与判断 | 推论是否成立，判断是否超出依据 |
| 结构与推进 | 各部分的组织与衔接是否有助于理解 |
| 语言与表达 | 措辞是否准确、清楚，表达是否服务于内容 |
| 视角与边界 | 前提、范围和重要视角是否得到恰当处理 |

评分在综合裁决完成后形成，不作为寻找问题的预设清单。综合质量、核心任务是否成立、结论把握度分别呈现。

## 安装

将整个仓库放入个人 Skill 目录。首次安装可在 PowerShell 中运行：

```powershell
git clone https://github.com/xuziqiu/xzq-text-audit.git "$HOME/.codex/skills/xzq-text-audit"
```

需要保留 `SKILL.md`、`agents/`、`references/`、`assets/` 和 `scripts/`，不能只下载入口文件。

如果已经存在同名目录，先检查本地版本与改动，不要直接覆盖。通过本仓库克隆安装、且没有本地改动的副本，可在该目录运行 `git pull --ff-only` 更新；正在进行的审计应先完成或保留旧版本，因为恢复校验会检查 Skill 是否变化。

## 使用

在 Codex 中明确调用，并提供完整正文：

```text
使用 $xzq-text-audit 审计这篇文章，核查会影响结论的重要事实，并给出完整报告。不要改写正文。
```

如需保存和续作：

```text
使用 $xzq-text-audit 审计这份报告，保存完整中间记录、事实来源、评分卡和最终报告，方便后续复核。
```

Skill 保持显式调用策略，普通审稿请求不会自动触发。

## 运行条件

- 本项目需要由支持 Skill 的 Codex 环境执行，不是独立桌面应用。
- 事实核查需要可用的外部检索能力；无法核实的内容和核查限制会在报告中说明。
- 无需保存或恢复时可以即时运行，不创建审计目录。
- 持久化与完整留痕运行使用 PowerShell 脚本；运行验证还需要可通过 `python` 调用的 Python 3 与 `jsonschema` 包。

```powershell
python -m pip install jsonschema
```

完整运行方式、阶段依赖和恢复规则见 [运行协议](references/runtime-protocol.md)。

## 内容与验证

`SKILL.md` 负责流程入口，`references/` 保存各阶段规则，`assets/` 定义运行清单与评分卡结构，`scripts/` 提供状态管理和验证。

在仓库目录中检查发布包：

```powershell
& ./scripts/validate-text-audit-skill.ps1
```

校验可以检查文件、引用、结构和完成条件；不能单独证明审计判断正确。真实文本的行为验证要求见 [回归说明](references/regression-suite.md)。
