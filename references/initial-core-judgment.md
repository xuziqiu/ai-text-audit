# 初读核心判断

在第一次完整阅读正文后、任何拆解和外部检索之前，保存一次整体阅读快照。它用于防止复杂流程遮蔽普通读者一眼即可感受到的总体问题或价值，不负责替代正式裁决。

## 隔离条件

- 只读待检正文以及正文自带标题。
- 不读作者背景、旧稿、既有审计、提示词或后续模块结论。
- 不建立声明表，不逐段打标签，不做外部事实核查。
- 不为了显得深刻而强行命名“底层逻辑”或作者动机。

## 记录内容

使用自然语言回答：

1. 第一眼的总体质量感受是什么；
2. 哪个问题、价值或关系最可能决定全文；
3. 文章表面上在完成什么任务；
4. 最直接的原文依据在哪里；
5. 哪些属于可见观察，哪些仍是待验证直觉；
6. 当前最值得后续检查的一至数个问题是什么。

不设固定条数。没有突出的总体洞察时直接说明，不制造。

## 冻结与回看

完成后冻结原稿和哈希。后续不得回写、润色或替换成事后聪明的版本。综合稿必须逐项说明初读判断最终被：

- 证实；
- 收窄；
- 补充；
- 或推翻。

初读判断与正式裁决不一致不是失败；无法解释为何变化才是流程缺口。
